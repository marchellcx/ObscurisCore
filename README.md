# ObscurisCore
This plugin is meant to server as a base for all features made for the Obscuris SCP: Secret Laboratory server.

# Features
- Optimization for LabAPI's events
  - For some reason they decided to call `GetInvocationList` which allocates a new array every time it's called for a lot of time sensitive events so I'm fixing that
- Coin gambling
- Loot tables
- Random events
- Random pickups
- Custom roles
- Round end statistics
- Vote commands
- Custom abilities
  - SCP Voice Chat
- Custom effects
  - RocketEffect
  - DoorInteractExplosionEffect
- Custom items
  - Impact grenades
  - Replicating SCP-018
  - SCP-207 without effects
  - SCP-1509 without respawn
  - Item launcher
  - Simple sniper rifle
- HUD
  - SCP-049-2 death alert
 
and more
